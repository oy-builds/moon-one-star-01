# The Moon Gets One Star

A one-star review of the Moon, in 120 characters or fewer. `main.ts` (Node 22, zero dependencies) writes the review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the kit's gate first: UTF-8, 1–120 characters, not only whitespace, single line.

Run it with `node main.ts`.
